학급 편집값 저장 누락 수정 (2026-10-22)

원인: App.tsx의 values()가 !n.disabled 조건으로 표 입력을 수집했습니다.
시험감독 표는 disabled=[]로 생성되므로 JavaScript에서 이 배열은 true로 평가됩니다.
그 결과 화면에서 수정한 표 전체가 저장 요청에서 빠지고 서버가 기존 값을 다시 저장했습니다.
저장 이력이 있다는 사실만으로 수정값이 반영됐다고 판단할 수 없습니다.

수정: disabled !== true일 때 입력을 전송합니다. 일부 열만 잠긴 표도 전송하며,
서버의 기존 수정 금지 열 검증은 그대로 유지합니다.

필수 덮어쓰기 파일:
frontend/dist/timetable.js
frontend/src/App.tsx

ZIP을 풀고 위 파일을 GitHub의 같은 경로에 덮어쓴 후 Streamlit Reboot 및 브라우저 새로고침.
진입점 timetable_app2.py 및 Secrets는 변경하지 않습니다.
배포용 JS도 포함되어 있어 npm 빌드 없이 이 수정 내용을 적용할 수 있습니다.

검증: 배포용 JS의 실제 values() 표현식에 대해 9개 검사 통과.
기존 조건에서 disabled=[]인 학급 편집 표가 누락되는 현상을 재현했습니다.
수정 조건에서 편집 표가 포함되고 완전 비활성 표와 비입력 컨트롤은 제외됩니다.
node --check frontend/dist/timetable.js 통과.
실제 운영 앱에는 아직 반영하지 않았습니다. 실제 시트 변경 테스트는 하지 않았습니다.

적용 후: 학급 값을 원하는 내용으로 편집 → 학급 설정 저장 → 최신 시험감독 자료 다시 불러오기.
학급입력 탭에서 수정한 학년·반이 유지되는지 확인합니다.
이 수정은 학급 외 시험감독 표의 같은 입력 누락 원인에도 적용됩니다.
