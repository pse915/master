개발 브랜치 이름: `integrate-exam-supervision`
운영 진입점: `timetable_app2.py` (이름 유지; 초기 실행 진단 보완)

## 포함한 변경

기존 Application/ReactPort/NodeRenderer/DataGrid를 재사용하여 **시험감독 관리** 메뉴와 9개 하위 화면을 추가했습니다. Python에서 기존 React 노드를 구성하며 별도 iframe, HTML 앱 삽입, 두 번째 운영 Streamlit 앱을 사용하지 않습니다. 기존 메뉴와 로그인·서비스 계정을 재사용합니다. 배정 엔진은 Apps Script의 후보 제한, 시드 난수, 매칭, 사전식 목적함수, 증분 평가, 단일 변경·교환 개선을 Python으로 옮겼습니다.

시험감독 시트는 기존 시간표·업무 스프레드시트와 분리합니다. 관리자는 기존 역할 검사 `can_manage_ids()`를 통과해야 합니다. `pse915` 문자열만으로 관리자 권한을 부여하지 않습니다. 일반교사는 기존 허용 탭과 별도 조회 허용 설정을 모두 만족해야 합니다. 본인 조회는 이미 인증된 기존 계정의 이름을 시험감독 명단에 유일하게 대응시키며, 요청에서 임의의 이름·ID를 보내 본인임을 주장할 수 없습니다. 동명이인은 조회를 중단합니다.

## 적용 순서

1. 운영 저장소와 양쪽 Google Sheets를 사본으로 백업합니다. 아래 검증은 합성 자료에서 실행했으며 실제 운영 시트 사본을 제공받아 검증한 것은 아닙니다.
2. 기존 저장소에서 기준 커밋과 현재 HEAD 차이를 확인하고 별도 브랜치를 만듭니다. ZIP 안의 전체 프로젝트를 새 저장소로 만들 필요는 없습니다. `changed-files.zip`에 들어 있는 파일만 같은 경로에 적용할 수 있습니다. 이후 운영 저장소가 변경되었다면 application.py 수정 위치를 비교하여 병합하세요.
3. 기존 Secrets를 그대로 유지합니다. 새 비밀번호·API 키·유료 서버는 필요하지 않습니다. 기존 `migration.allow_writes`가 false이면 시험감독 쓰기도 차단됩니다. 검증용 사본에서만 기존 쓰기 설정을 활성화하세요.
4. 테스트용 Streamlit 앱을 같은 저장소의 개발 브랜치, 같은 `timetable_app2.py` 진입점으로 배포합니다. 기존 Cloud 설정 및 운영 앱 주소를 변경하지 않습니다. `frontend/dist` 빌드 산출물도 반드시 포함하세요.
5. 아래 연결 절차로 **복제한 시험감독 Sheets**를 등록합니다. 원본 Code.gs와 Index.html은 `reference/exam-original/`에 보존되어 있습니다.
6. TEST_RESULTS.md의 미검증 항목을 테스트 앱에서 확인합니다. 관리자 검토 후 개발 브랜치를 기존 main으로 병합하면 기존 운영 주소와 진입점으로 반영할 수 있습니다. 이 전달본은 원격 push·main 병합·운영 배포를 수행하지 않았습니다.

## 관리자 시트 연결

1. 시험감독 Google Sheets를 기존 Streamlit 서비스 계정 이메일에 편집자로 공유합니다. 기존 `gcp_service_account` 등 프로젝트에서 사용하는 인증 설정을 그대로 씁니다. 개인 이메일·비밀번호를 새 코드에 적지 않습니다.
2. 기존 관리자 계정으로 로그인하고 **시험감독 관리 → 연결·권한 설정**을 엽니다.
3. 시험감독 Google Sheets 주소 또는 ID를 입력하고 **연결 검사**를 누릅니다. 시트 제목·주소·누락 탭·헤더 오류를 확인합니다. 기존 시간표/업무 시트 ID는 등록을 거절합니다.
4. **연결·조회 권한 저장**을 누르면 기존 업무 스프레드시트의 새 `시험감독_통합설정` 탭에 연결 정보를 저장합니다. 세션·로컬 파일에만 저장하지 않으므로 서버 재시작 후에도 유지됩니다. 기존 업무 탭의 데이터를 수정하지 않습니다.
5. 아래 저장 주체 절차를 먼저 완료한 뒤 **누락 시트·필수 열 준비 및 이전 기록 확인**을 누릅니다. 기존 자료를 초기화하지 않고 누락된 탭/필수 열을 준비합니다. 헤더가 예상과 다르거나 state JSON이 손상되면 자동 덮어쓰기를 중단합니다.
6. 일반교사에게는 기존 **아이디·권한 관리 / 회원별 탭 권한 관리**에서 `시험감독 관리`를 허용합니다. 연결 화면에서 본인 조회와 전체 조회 허용 여부를 추가로 설정합니다.

다른 학교 사본으로 바꾸려면 새 주소를 검사하고 저장합니다. 현재 열린 Sheets를 자동 식별하지 않습니다. 테스트 설정과 운영 설정은 각 앱의 업무 Sheets 설정에 따르므로 복제 검증 시 업무 Sheets도 분리하세요.

## 기존 GAS와 같은 시트 사용

Google Sheets에는 두 앱에서 사용할 수 있는 일반적인 CAS가 없습니다. Python 프로세스 잠금과 Apps Script LockService가 서로를 잠근다고 가정하지 않습니다. 이 구현은 **한 번에 한 앱만 쓰는 소유권 프로토콜**을 사용합니다. 양쪽 동시 쓰기는 지원하지 않습니다.

- 기존 GAS를 계속 쓸 경우에만 `compatibility/Code.gs` 전체를 바인딩된 Apps Script의 Code.gs로 적용하고, 동일한 Index.html을 유지합니다. 해당 스프레드시트 편집기의 Apps Script에서 `installIntegrationProtocol`을 한 번 실행하고 변경한 웹앱 버전을 기존 배포에 적용하세요. 일반적인 시트 연결에는 코드 수정이 필요 없으며, 이 동반 패치는 같은 시트에 저장하는 두 앱의 전환을 위한 것입니다.
- 통합 화면에서 저장 주체를 Streamlit으로 선택하면 우선 `PAUSED`가 됩니다. 기존 GAS 요청의 최대 실행시간 6분보다 긴 **6분 30초**가 지나면 최신 자료를 불러오고 전환 적용을 다시 누릅니다. 대기 중에는 어느 앱도 저장하지 않습니다. 동반 GAS는 실시간 소유권 키를 읽어 쓰기·초기화·마이그레이션을 차단합니다.
- Streamlit→GAS는 계산 결과를 자동 저장하지 않고 저장 단계에서 소유권과 최신 자료를 재검사하므로 즉시 전환할 수 있습니다. 진행 중인 계산을 취소하고 전환하는 것을 권장합니다.
- GAS에서 편집하지 않는 전용 시험감독 시트라면 **이 시트를 Apps Script에서 편집하지 않고 통합본에서만 사용합니다**를 선택하고 Streamlit으로 전환할 수 있습니다. 이 옵션은 기존 GAS와 병행 쓰기를 허용하지 않습니다.
- 수동 Sheets 편집은 위 프로토콜을 따르지 않습니다. 저장 도중 수동 편집을 멈추세요. 저장 전 전체 스냅샷 해시 비교와 저장 후 검증으로 충돌을 감지하지만, 외부 편집과 완전한 CAS를 보장하지는 않습니다. 여러 Streamlit 서버가 같은 시트에 동시에 쓰는 배포도 지원 범위 밖입니다.
- 동반 GAS의 기존 로그인 구현은 별도의 보안 개선 대상입니다. Python 통합본은 해당 인증 우회 코드를 사용하지 않습니다. 동반 패치 적용만으로 GAS 인증이 강화되었다고 해석하지 마세요.

실제 GAS 배포와 Python이 같은 복제 시트에서 전환하는 검증은 아직 수행하지 않았습니다. 운영 전 복제 시트에서 필수 확인하세요.

## 사용과 저장

- 명단·시험일정·조건표는 표 편집 또는 TSV/CSV 붙여넣기로 입력합니다. 변경 시 미저장 표시가 나오며 저장 실패 시 편집 상태가 유지됩니다. 교사 삭제는 삭제 대상으로 명시해야 합니다. 기존 교사 ID 변경은 금지됩니다.
- 고급 감독 설정과 학년별 운영 설정은 JSON 편집도 지원합니다. 원본과 동일한 최적화 옵션을 검증하여 저장합니다. 자습감독 0~2명, 역할 O/X, 강사 제외, 미등록 시간표 교사의 명시적 부족 인원 투입 조건을 유지합니다.
- 자동 배정/개선은 백그라운드에서 계산합니다. 새로 확인 버튼으로 진행 상태를 보고 **계산 결과 검증 후 저장**을 눌러야 시트에 반영됩니다. 계산 중 메뉴 전환이 가능합니다. 서버 재시작 시 저장하지 않은 계산은 유실되며 시트의 기존 배정은 유지됩니다.
- 직접 변경·교환·정/부감독 교환은 하드 제약을 검증합니다. 기존 오류가 있는 배정은 오류를 엄격히 줄이고 새 오류를 만들지 않는 수동 수정만 허용합니다.
- 저장은 변경된 셀의 userEnteredValue만 하나의 원자적 Sheets batchUpdate에 보냅니다. 변경하지 않은 사용자 열·수식·서식을 덮어쓰지 않습니다. 명시적으로 삭제된 관리 행과 변경된 관리 셀은 변경됩니다. 응답 유실·검증 실패는 저장 결과 불명 상태로 처리하고 다시 불러오기 전 재저장을 막습니다. 자동 롤백으로 외부 변경을 덮어쓰지 않습니다.
- 배정결과 시트를 직접 수정한 경우 최신 자료 조회에서 해석하고 다음 저장 시 검증 후 초안·통계·시간표에 반영합니다. 조회만으로 시트에 쓰지 않습니다.
- 전체 시간표는 학년/날짜/교시/학급 필터, 카드 보기와 가로 스크롤 표를 제공합니다. 개인·전체 CSV와 인쇄용 HTML을 내려받을 수 있습니다. 내려받은 HTML을 열어 인쇄/PDF 저장을 누르면 메뉴·버튼 없이 출력합니다. 운영 앱에 기존 Index.html을 삽입하지 않습니다.
- 이전 배정버전은 청크/해시를 검증한 읽기 전용 조회입니다. 현재 원본의 EDITABLE 흐름을 유지하며 과거 확정·잠금·복원 기능을 새로 활성화하지 않았습니다.

## 원본에서 유지한 특성 및 범위

원본 validateSchedule_의 시험기간 5일 제한은 실제로 **학년·일차 조합 수**를 검사합니다. 이 동작을 임의로 고치지 않았으므로 다학년 일정은 단순 달력 5일보다 먼저 거절될 수 있습니다. 정책 변경은 별도 결정이 필요합니다.

비용함수/규칙/시드 매칭의 동등성은 합성 입력으로 비교했습니다. 시간 제한을 사용하는 전체 최적화 결과가 어떤 장비에서도 동일하다는 보장은 없습니다. 실제 교사 수·최대 일정 규모·학교의 수동 편집 방식에서 운영 전 확인해야 합니다. 시간표 데이터 자동 가져오기는 추가하지 않았으며 기존 시간표 데이터는 시험감독 저장으로 역수정되지 않습니다.

## 복구

운영 장애 시 기존 기준 커밋으로 코드/빌드 산출물을 되돌립니다. 시험감독 시트가 GAS 소유였고 계속 사용할 경우 통합 화면에서 GAS로 전환한 뒤 되돌립니다. 원본 GAS를 패치 없이 복원하기 전에는 Streamlit 저장을 중지하고 관리자 간 전환을 확인하세요. 데이터 복구는 검증용이 아닌 운영 전 백업 Sheets를 기준으로 별도 확인하여 수행합니다. 오류를 이유로 앱에서 자동 초기화하지 않습니다.
